# Identidade Visual

A CAST Store segue a identidade visual oficial CAST — na loja, no painel e neste portal
de documentação.

## Logo

- Logo oficial **CAST > STORE** em duas versões:

| Versão | Arquivo | Uso |
|---|---|---|
| Branca | `assets/logo-store-white.png` | Fundos escuros — topo, carrinho |
| Navy | `assets/logo-store-navy.png` | Fundos claros — telas de login |

- **Tagline:** Driving Futures.
- **Favicon:** chevron CAST (SVG).

## Tokens deste portal

Como a paleta foi aplicada no CSS da documentação (`assets/css/style.css`):

| Token | Cor | Onde aparece |
|---|---|---|
| `--accent` | `#3F00E5` | Links, item ativo da sidebar, borda dos cards |
| `--accent-dark` | `#0E004B` | Início do degradê do topo, títulos, blocos de código |
| `--accent-cyan` | `#00F0FF` | Sigla "CAST Store", sublinhado do menu ativo, tagline |
| `--accent-magenta` / `--accent-blue` | `#FF13FF` / `#01A3F8` | Filete degradê sob o topo, borda dos cards |
| `--border` | `#E9E9EF` | Bordas e divisores |
| `--muted` | `#777777` | Textos secundários |
| `--text` | `#121212` | Texto e rodapé |
